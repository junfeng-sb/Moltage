# Moltage v0.2.2.1 — Pre-release

A Windows x64 maintenance release with performance improvements and GUI fixes.
Existing v0.2.2 downloads remain available unchanged.

## Highlights

- Faster project refresh through batched local indexing and a shared Slurm queue query.
- Fewer redundant WBL hashes and large-file transfers, using verified server-side copies.
- Faster Au electrode roll searches and lattice previews without changing scientific rules.
- Fix reopening a structure after closing the last Geometry tab.
- Fix premature WBL setup cancellation and a Windows crash after manual contact selection.

## Downloads

Use `Moltage-Setup-0.2.2.1.exe` for Windows. English and Simplified Chinese PDF
manuals accompany this release. The installer is unsigned. Application source,
third-party corresponding source, and SHA256 checksums are provided alongside it.

## Scope and cautions

FHI-aims, AITRANSS, and ORCA are not included; configure your own lawful installations.
WBL remains a linker-parameterized model hypothesis, not explicit Au–molecule–Au
DFT-NEGF. This update introduces no new scientific parameters or dependency versions.

Project schema 12 and display-preference schema 3 are unchanged from v0.2.2.
Back up project records and keep any WBL results you need before recalculating.
Older versions cannot be assumed to read updated records. Uncertain remote writes
require manual inspection and are not automatically retried.

Import only completed, stable ORCA directories. Custom/per-element basis overrides
are not fully interpreted: verify settings and use manual AO selection when needed.
A stopped import may leave a reported partial destination. Keep result JSON files
alongside TXT exports to preserve parameters and model provenance.

Offline tests and local binary smoke tests do not establish compatibility with
every external HPC environment or replace fresh-machine installation acceptance.
