# Moltage v0.2.2 — Pre-release

An updated Windows x64 development release. Existing v0.2.1 downloads remain
available unchanged.

## Highlights

- Import completed remote ORCA optimizations and continue directly to WBL.
- Recalculate WBL Step 2 with edited parameters and safely replace its results.
- Export full ORCA WBL transmission grids as tab-delimited TXT for Igor Pro.
- Restore the explicit NCS terminal-sulfur all-p comparison model.
- Improve WBL reports, leading-orbital annotations, and interactive plot settings.
- Verify wavefunctions on the server during status refresh, avoiding large downloads.
- Remember the Bond Detection factor across application restarts.

## Downloads

Use `Moltage-Setup-0.2.2.exe` for Windows. English and Simplified Chinese PDF
manuals accompany this release. The installer is unsigned. Application source,
third-party corresponding source, and SHA256 checksums are provided alongside it.

## Scope and cautions

FHI-aims, AITRANSS, and ORCA are not included; configure your own lawful installations.
WBL remains a linker-parameterized model hypothesis, not explicit Au–molecule–Au
DFT-NEGF. No numerical coupling defaults or new scientific datasets are introduced.

Back up project records and export any WBL results you want to keep before
recalculating. An uncertain remote write is reported for manual inspection, not
automatically retried. This release writes project schema 12; older application
versions cannot be assumed to read newly saved records. Saved display preferences
also move to schema 3; back up `view_preferences.json` before upgrading if you
need to return to v0.2.1. Do not use mixed versions on the same updated records.

Import only completed, stable directories. Custom/per-element basis overrides
are not fully interpreted by import: verify the recorded settings and use manual
AO selection for such inputs, rather than relying on automatic basis mapping.
Stopping an import after destination creation can leave a partial copy whose path
is reported for manual inspection. TXT exports contain numerical columns only;
retain the result JSON alongside them for parameters and model provenance.

Offline validation does not establish compatibility with every external HPC
environment.
