Moltage 更新日志

============================================================
0.1.13 to 0.2.1
============================================================

新增

- 新增 ORCA 运行时配置：服务器设置按 FHI-aims 与 ORCA 分类；Slurm 可对主流 ORCA 5.0.x、6.0.x 和 6.1.x 安装执行有界搜索，Slurm/LSF 均支持手动配置和验证。
- 新增 ORCA 两阶段项目流程：Step 1 提交、监测、取回和重提交分子优化，并可独立运行 frequency verification；Step 2 使用已验证的 .gbw 和 orca_2json 证据计算 linker-parameterized WBL transmission，不重新运行 SCF 或几何优化。
- WBL 设置支持 linker/contact 自动识别、原子手动点选、左右 Γ₀ 和能量窗口配置；结果可持久化 transmission 数据、轨道贡献和 provenance，并在 Transmission viewer 中查看。

工作流与界面

- Calculation 菜单按 External Programs 与 Local Analysis 分类，FHI-aims 与 ORCA 各自拥有独立子菜单。
- ORCA 项目显示 Optimization/WBL 两盏状态灯；Project Manager 只显示与所选 workflow 相关的操作，底部操作区改为两行布局。
- 项目状态 Refresh 新增有界 timeout 和即时 Stop；后台刷新不再阻塞主窗口关闭。

科学语义与显示

- WBL 结果明确标记为 HYPOTHESIS，不冒充显式 Au–molecule–Au DFT-NEGF；用户输入的 Γ₀ 与轨道子空间选择会记入 provenance。
- 自旋多重度为 1 时直接计算含自旋简并语义的总 transmission，不再分别展示重复的 Alpha/Beta 曲线；对数坐标轴统一使用 10ⁿ 上标格式。

修复

- 修复 ORCA Slurm 脚本输出重定向、Step 2 提交与完成状态、Transmission 打开、Step 1 重提交闪退，以及 ORCA 恢复路径误依赖 FHI-aims control.in 的问题。
- 修复 Qt/VTK 关闭时 native window、interactor 与 render window 释放顺序冲突，不再出现 wglMakeCurrent error 6 或延迟 heap corruption。

发布准备

- 项目以 GPL-3.0-only 发布，版权主体为 Junfeng Lin；新增第三方组件声明、许可证文本、私密安全报告指引以及应用内 About/License 入口。
- Windows 安装器会展示并安装项目许可证与第三方声明；同一 GitHub Release 必须同时提供 Moltage 源码和经 SHA-256 验证的第三方对应源码包。
- 打包配置移除未使用的 Qt Virtual Keyboard、Qt PDF、Qt QML 和 Qt Quick 模块；FHI-aims、AITRANSS 与 ORCA 仍由用户自行提供，不进入安装包。

验证

- 完整离线测试：1482 passed, 2 skipped。该证据不代表对所有外部 ORCA/HPC 环境的兼容性承诺。
- Windows packaging 已通过 PyInstaller/Inno Setup 构建：安装器与应用版本资源均为 0.2.1，SHA-256 记录与安装器匹配，打包应用通过隔离本机状态的启动 smoke check。

0.1.12 to 0.1.13
============================================================

新增

- 服务器配置新增 FHI-aims species definitions root：运行时发现可自动填写，失败时可在同一配置界面手动指定；新建 control.in 只读取所选服务器上的精确元素定义，不再依赖应用内置副本。
- Slurm 配置新增可选 account、partition、qos，LSF 配置新增可选 queue、project；留空时明确使用 scheduler/site default，不进行自动猜测。
- 新增 MoltageAuPyramidV1 参数化 Au 金字塔生成器，支持 2–10 层并默认生成六层 Au56；标准原子、apex、reference corners、layer/lattice identity 和 $nlayers 来源均具有显式 provenance。
- 新增 Au(111) canonical lattice extension：可在左右电极的独立 layer 上添加 Phase-2 合法候选，保存稳定的 side + layer + lattice key identity，并纳入既有 Geometry Undo/Redo 和同侧刚性旋转。
- Au extension hover 新增预测显示：可添加位置显示金色半透明 Au、蓝色虚线预测键和向外渐隐的三角晶格平面；碰撞位置保留为红色 preview 且禁止添加。

兼容性与修复

- 旧 server profile 保持可读取；新增 scheduler admission 字段为空时不生成相应指令，旧 LSF profile 保留原有 structured span/rusage 行为，同时允许新配置显式选择 site default。
- 修复 Step 4 AITRANSS 绕过 runtime configuration 调用裸 srun 的问题；srun 模式现在只接受已发现、配置并验证的绝对 launcher，缺失时明确失败。
- 移除固定 Au59 模板、variant A/B 和固定原子数量假设；历史项目只在 reference mapping 可唯一恢复时迁移，既有计算输入和历史 $nlayers 不会被重写。

科学资源与发布准备

- 将 Au placement 参数明确记录为 Moltage 可编辑的 initial-geometry heuristic defaults，不再把精确数值表述为实验常数或特定论文的逐值来源。
- Covalent radii 改用 BODR/Pyykkö 数据，van-der-Waals radii 改用 Charry–Tkatchenko ChemRxiv v2 数据，并记录单位转换、版本、来源和再分发许可。
- 默认测试与真实 SSH、HPC、FHI-aims 和 scheduler 环境隔离，使用 synthetic fixtures；运行时 workspace、下载、cache 和临时数据不再以 repository root 作为默认写入位置。
- 清理准备公开仓库时发现的真实环境痕迹、科研命名、runtime UUID 和来源不明确的旧 UI 资源；不把本机配置、凭据或真实服务器 capture 打入发布内容。

验证

- 完整离线测试：1332 passed, 2 skipped；OpenSpec strict validation 通过。

0.1.5 to 0.1.6
============================================================

新增

- 添加本地紧束缚 Transmission 工作区：可从当前结构选择或填写左右电极接触原子，按元素/键类型批量设置参数，并对单个原子或键进行覆盖。

优化

- 优化紧束缚结果与参数显示：Transmission 曲线仅在参数完整并点击 Calculate 后于独立窗口打开；原子能量和键耦合改为鼠标悬停时临时高亮并显示，离开后自动清除，避免遮挡结构。Hamiltonian 矩阵仍可关闭或浮动，该功能不创建远端任务或 AITRANSS 结果。
- 将 Slurm 与 LSF 提交资源拆分为独立界面和语义：LSF 使用 MPI job slots、span 主机分布和 rusage 内存预约，不再套用 Slurm 的 CPUs-per-task、每节点硬内存限制或 SLURM_EXPORT_ENV；两类调度器的非重排、环境隔离、输出和邮件选项分别生成对应指令。
- 重构 Runtime Discovery 为定向证据搜索：依次复用已填约束、规范化 PATH、真实安装根的 bin/scripts/libexec 邻接关系、可用的 plocate/locate 索引、程序 module 元数据及 ELF 缺失库线索；自动路径不再递归扫描目录，也不再穷举 MPI×MKL module 组合。
- 完善 Runtime Discovery 缺失反馈：仅路径、环境和 FHI-aims MPI 启动器均完整的候选才会自动填入；部分候选保留为诊断，并逐项给出缺失字段、可能的 aims*.x/aitranss*.x/mpirun/srun 名称和 Manual Configuration 手动填写位置；FHI-aims 尚未定位时仍会保留独立发现的 MPI 启动器候选，但不会未经兼容性确认就自动写入。
- 将含义不直观的 Scheduler standard output file 更名为 Output file name：该字段仅接受相对于任务工作目录的安全文件名，允许在确认后暂存空白配置，但提交前仍明确要求补全。只读 SFTP 文件夹按钮迁移到 Server Connections 的 Remote project workspace，只选择已有远端目录，不选择或拼接输出文件。

修复

- 修复 LSF 自动检测与实际提交环境不一致的问题：通过只读 lsid 验证完整的 LSF_ENVDIR、LSF_BINDIR、LSF_LIBDIR、LSF_SERVERDIR 客户端目录集；自动检测仅使用当前/登录环境公布的变量和由命令目录推导的少量标准安装布局，不定位或复用特定 FHI-aims/提交脚本，也不扫盘。三个额外目录会写入非敏感服务器配置，并与已验证命令目录一起在提交、状态查询、历史查询和取消命令中逐次显式注入。验证错误现在明确区分命令组缺失、目录集不完整和 lsid 拒绝。
- 修复 LSF 输出与终态回收：提交时用 -cwd 显式绑定任务目录，用户指定的输出文件在任务启动时立即创建并持续接收纯程序输出，LSF 延迟报告改写入派生的 .lsf.log；监测使用 bjobs 与不会阻塞的 bhist，正确返回超时、内存不足和取消原因，不再调用目标服务器上会挂起的 bacct。
- 修复 Runtime Discovery 会被远端 PATH 中含重复分隔符、. 或 .. 的单个命令路径中断的问题：只读查询先规范化候选目录，解析时隔离并报告仍不安全的候选，而最终保存和执行的路径继续接受严格规范化校验。
- 修复目标式 Tcl Modules 环境中的 Runtime Discovery：接受模块列表仅用于显示的前导 /，先用 ELF 缺库完成 MKL/MPI 环境再搜索程序 module，允许“多个库缺失降为一个启动器缺失”的有效中间状态，并用完成后的 FHI 环境重新搜索 AITRANSS；补充常见精确文件名、折叠重复部分候选，并限制可选分支且预留命令预算，避免相同文件被重复验证直到全局上限。
- 修复 namespaced Tcl Modules 服务器的自动运行时检测：不再依赖 module avail mkl 的站点匹配行为，而是一次读取并按 ELF 缺失库族过滤模块目录；从规范化 PATH 目录只检查浅层、名称定向的 opt/apps/software/*aims* 布局，因此可找到未导出到 PATH 的同安装树 AITRANSS，而不执行环境脚本或全盘扫描。候选按 ELF 路径中的版本证据排序，mpirun 仅在其安装树与实际解析到的 MPI 库一致时自动采用。

- 添加了测量栏 Clear 按钮，一键清除当前标签页的全部测量及临时点选标记，并保留测量模式。
- 添加带英文帮助的 FHI-aims / AITRANSS 手动运行环境配置窗口，支持无 module 的安装方式以及根据已填字段定向补全。

优化

- 优化电子密度差交互：点选原子可再次点击取消，框选仅显示透明虚线边框，片段编号即时生效并随输入框自动切换活动片段；提交时会列出所有遗漏原子，恢复后的密度结果在独立只读视图中显示。
- 统一电子密度差任务的资源与状态界面：运行时长按小时输入并在后台换算为分钟，右侧三盏标准状态灯分别显示 Total、Subset 1、Subset 2 进度，右键可安全取消三者共用的当前 Slurm 作业。
- 增强了轨道曲面渲染并修正显示面的光照朝向。
- 优化了 Isosurface 设置布局，将等值面与光照材质分为左右两栏，新增材质参数可随用户设置保存至下次启动。
- 调整了测量栏出现时机，仅在首个距离或角度结果产生后显示，启用工具和未完成点选时不再改变视口布局。
- 加快了服务器运行环境检测，优先复用路径与安装结构线索、合并并按需停止 module 查询，支持区分同名 MPI 多路径及发现不同文件名的 AITRANSS，并明确提示尚未验证的版本兼容性。
- 电子密度差任务复用普通计算的删除规则：终态任务可移入并恢复自项目回收站，也可在关闭相关标签页并复核权威任务记录后永久删除；活动或状态未决任务仍禁止删除。

修复

- 修复了手动载入 .next_step 文件时无谓要求配套 .in 文件的问题；现在直接读取该文件自身的完整结构。
- 修复了 Step 4 有效结果因 AITRANSS 运行后改写 `tcontrol` 而停留在黄色问号的问题；提交后 SHA256 差异仅作诊断，成功仍由当前作业输出、完成标记和 `TE.dat` 网格共同判定。
- 修复了 `$ecp off` 的 AITRANSS 仅写入 `$efermi` 时被误报为结果注释不完整的问题，并继续严格核对费米能与 `TE.dat`。
