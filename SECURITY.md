# Security Policy

## Supported version

Security fixes are evaluated for the newest development release only. Moltage
is pre-1.0 software; users should update to the latest release before reporting
or reproducing an issue.

## Private reporting

Please do not disclose a suspected vulnerability, credential exposure, or
privacy leak in a public issue. Use GitHub's **Security → Report a
vulnerability** private-reporting form for this repository. If that form is not
available, contact the maintainer through the GitHub profile without including
technical details and request a private channel.

Include the affected Moltage version, operating system, reproduction steps,
impact, and whether real server credentials or research data may have been
exposed. Do not attach real credentials, private keys, or confidential research
files.

## Scope boundary

FHI-aims, AITRANSS, ORCA, SSH servers, schedulers, and HPC sites are external
systems supplied and administered by the user. Reports about Moltage's handling
of those boundaries are in scope; vulnerabilities in the external products or
sites should be reported to their respective maintainers.
